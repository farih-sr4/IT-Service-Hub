# IT-Service-Hub
Salesforce application that allows employees to submit IT issues and service requests while helping the IT team triage, assign, resolve, escalate, and report on them.

### Problem statement
Nimbus technologies need a centralized system for recording, assigning, resolving, and reporting on IT incidents and service requests.

### MVP Scope

The first release will provide:
- Incident submission
- Priority calculation
- Ticket assignment
- Status tracking
- Resolution recording
- SLA target tracking
- Technician reports
- Management dashboard

### Out of scope for MVP

- AI chatbot
- Slack or Microsoft Teams integration
- Automatic device discovery
- Predictive incident detection
- External monitoring integration
- Full CMDB
- Mobile application
- Complex release management
